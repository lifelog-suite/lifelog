# LifeLog

A growing suite of apps to track, organize, and improve everyday life.

## The suite

- **MenuLog**
- **PatriLog**
- **NutriLog**
- **WalkieLog**
- **TrainLog** — planned

More apps will join the suite as it grows.

## About this repository

This repository is the central home for LifeLog:
an overview of the suite, shared documentation, and future plans.

Each app is developed independently. Links to individual
repositories will be added as they become available.
